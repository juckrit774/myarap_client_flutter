# รายการรูปภาพที่ต้องถ่าย

โฟลเดอร์นี้เก็บ screenshot ประกอบคู่มือการติดตั้ง  
บันทึกเป็น PNG ความกว้างแนะนำ **800 px** ตั้งชื่อตามด้านล่าง

---

## Windows (ต้องถ่ายจากเครื่อง Windows)

| ชื่อไฟล์ | สิ่งที่ต้องแสดงในรูป |
|---|---|
| `win_smartscreen_1.png` | หน้าต่าง SmartScreen "Windows protected your PC" |
| `win_smartscreen_2.png` | หลังคลิก "More info" — แสดงปุ่ม "Run anyway" |
| `win_properties_unblock.png` | File Properties → แท็บ General → ช่อง Unblock |
| `win_uac.png` | หน้าต่าง User Account Control (UAC) |
| `win_installer_welcome.png` | Setup Wizard — หน้าแรก Welcome |
| `win_installer_finish.png` | Setup Wizard — หน้าสุดท้าย Installation Complete |
| `win_tray_icon.png` | ไอคอน MyARAP ใน System Tray (มุมขวาล่าง) |
| `win_tray_menu.png` | เมนูคลิกขวาที่ไอคอน Tray แสดง Open / Exit |

## macOS (ถ่ายจากเครื่อง Mac)

| ชื่อไฟล์ | สิ่งที่ต้องแสดงในรูป |
|---|---|
| `mac_blocked_dialog.png` | Dialog "MyARAP cannot be opened because..." |
| `mac_rightclick_open.png` | Finder → คลิกขวาที่ MyARAP.app → เมนู Open |
| `mac_open_confirm.png` | Dialog ยืนยัน "Are you sure you want to open it?" — ปุ่ม Open |
| `mac_system_settings.png` | System Settings → Privacy & Security (Ventura+) |
| `mac_open_anyway.png` | ปุ่ม "Open Anyway" ในหน้า Security |
| `mac_dmg_window.png` | หน้าต่าง DMG — ลาก MyARAP.app ไป Applications |
